# Shubh Wade · Portfolio

React + Vite + Tailwind CSS v4, shadcn-style components (Radix), Motion and Lenis.

```bash
npm install
npm run dev      # local dev server
npm run build    # static build in dist/
```

Deploys as a static site. On Vercel or Netlify, import the repo: the framework is detected as Vite, the build command is `npm run build` and the output folder is `dist`.

Static files (photo, résumé) live in `public/assets/`.
