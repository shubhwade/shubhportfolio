02 · Selected work

Finance tools I've built

Each one started as a question I had as an analyst. All of them are live and run on public data.

Flagship Open source · Python

Isoline

Financial statements, measured precisely.

An analysis engine for any listed company, run from the terminal. It computes Piotroski F, Altman Z″ and Beneish M scores alongside DuPont ROE, ROIC, accruals and a DCF with sensitivity tables. It then writes a print-ready report that explains every number in plain English. Missing data shows as n/a with a note and is never filled in as zero.
